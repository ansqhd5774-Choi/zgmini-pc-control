# 보조 저장소 담당 소속

정본은 메인 저장소의 [저장소·담당 브랜치 기준](https://github.com/ansqhd5774-Choi/zgmini/blob/main/docs/REPOSITORY_ROLES.md)이다. 이 파일은 정본 위치를 안내하며 별도의 프로젝트 전체 정책을 만들지 않는다.

- 프로세스 총괄: 메인 `zgmini / codex/controller-ops-lessons-20261105`.
- 이슈 담당자: 보조 `zgmini-pc-control / codex/issues-lifecycle-manager-20261118`.
- 자동화 담당자: 보조 `zgmini-pc-control / codex/pc-automation-process-improvement-20261119`.

보조의 구 `codex/controller-ops-lessons-20261105`는 역사 참조용으로 보존한다. 신규 총괄 계획은 메인 동명 브랜치에서 관리한다. PC 자동화 코드·승인·설치/복구 원장·결과는 이 저장소에 유지한다. 이슈 담당자의 양 저장소 이슈 처리를 금지하거나 기능 담당자의 독립 업무에 새 승인 단계를 추가하는 규칙이 아니다.
