## 4. 보고 근거·실행 범위

- **1단계 등록·접근:** 사이트맵 36개와 등록부 36개 동일. 홈페이지 포함 36/36 공개 URL GET HTTP 200; 대표 6페이지 제목·H1 확인(서버 HTML 증거).
- **2단계 공식 발표:** BLS/BEA/뉴욕연은 공식 8종 발표와 미도래 일정 구분. FRED/BLS 개별 시계열 실수치 4개 및 정확 단위 대조. CPI/PCE/PPI 헤드라인과 다른 세부 원지수는 숫자를 섞지 않음.
- **3단계 PC:** 기존 A급 체크포인트·예전 diff를 시점 한정 재사용. 실제 원시계열 읽기 A operation 부재로 단계 미완료. 수집·계산·게시·DB 운영 쓰기 없음.
